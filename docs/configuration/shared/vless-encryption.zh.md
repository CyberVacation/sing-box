### 结构

VLESS 出站：

```json
{
  "encryption": "mlkem768x25519plus.native.0rtt.<public-key>"
}
```

VLESS 入站：

```json
{
  "decryption": "mlkem768x25519plus.native.600s.<private-key>"
}
```

省略、留空或设为 `none` 会禁用加密。启用加密时，`flow` 必须留空。

### 字段

#### 模式

第二段用于选择模式。客户端与服务端必须一致。

| 模式 | 描述 |
| --- | --- |
| `native` | 不使用额外混淆。 |
| `xorpub` | 混淆公钥交换。 |
| `random` | 混淆公钥交换与记录头。 |

#### 握手

客户端：`1rtt` 始终执行完整握手。`0rtt` 允许在首次完整握手后恢复会话。

服务端：会话票据有效期，以秒为单位，例如 `600s`；也可使用包含两端的范围，例如 `300-600s`。
有效值为 0–65535。单一数值会在其一半至完整数值之间选择；`600-600s` 表示固定有效期。
`0s` 会禁用会话恢复。

#### 密钥

使用一个服务端密钥，以无填充的 base64url 编码：

| 密钥类型 | 客户端公钥 | 服务端私钥 |
| --- | --- | --- |
| X25519 | 32 字节 | 32 字节 |
| ML-KEM-768 | 1184 字节 | 64 字节种子 |

不支持中继密钥链与自定义握手填充。
